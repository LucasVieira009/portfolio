## Como ler cada projeto

Cada pasta tem um `README.md` com a mesma estrutura:

1. **Resumo** — o que quebrou, por que e o que foi feito
2. **Sintoma** — a mensagem de erro exata
3. **Hipóteses que caíram** — o que eu testei e descartei
4. **A virada** — o comando/log que revelou a causa
5. **Correção** — código real, não pseudocódigo
6. **Resultado** — estado final verificável
7. **Aprendizados** — o que levo pro próximo problema
